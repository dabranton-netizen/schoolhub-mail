Privacy Policy

SchoolHub Mail is a personal tool used only by its owner on his own computer.

  • Data accessed: email in the owner's own Gmail accounts, via the Gmail API (read/modify and send).
  • Storage: sign-in tokens are stored encrypted on the owner's computer. Email content is shown to the owner and is not copied to any server.
  • Sharing: no data is sold, shared, or transferred to anyone.
  • Google API data use follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion: the owner can revoke access any time at myaccount.google.com/permissions.
